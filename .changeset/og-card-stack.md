Put Angular, Azure, Terraform and GitHub Actions on the sharing card, and give
the card a URL that changes when the card does. The technology line was one row
of SVG text, which does not wrap — four more names would have run off the edge
of the 1200px canvas — so it is now two rows, stack above and platform below.
The card also sat at `/og.png` forever, so scrapers that had cached it never
asked again: Discord was still serving the version from before "AI Engineer" was
in the role while reading the new title off the same page. The script that draws
the card now writes its fingerprint beside it, and the URL carries it.
