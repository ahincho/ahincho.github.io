Let the portfolio keep its own numbers. Each project now carries a like anyone
can give and take back, the hero terminal shows unique visits, and CV downloads
are counted without being displayed. The counter Worker grew a reactions family
alongside the counters: a reaction is one row per person, so the total is a
count of those rows and undoing a like cannot leave the number and the rows
disagreeing, and the endpoint reports which likes are yours so a fresh page load
never shows a pressed button as unpressed.

Visitors are identified by a salted hash of address and browser that stores
nothing personal — carrying the date for a visit, so it expires at midnight, and
omitting it for a reaction, which has to outlive the night. The footer now says
so plainly. With `PUBLIC_COUNTER_URL` unset the site builds exactly as before,
without so much as a script for any of it.
